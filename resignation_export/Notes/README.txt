=== Notes Directory ===

This folder contains meeting notes and personal reminders.

Important: Some notes contain sensitive context. If you need
to access any protected materials related to this export,
remember that standard verification is based on content
integrity — specifically, the cryptographic fingerprint of
the original meeting record serves as the access credential.

Use the first 16 characters of the SHA-256 digest.

Files:
  meeting_minutes.md   — Weekly sync notes
  todo_list.txt        — Personal task list
  draft_email.txt      — Unsent draft
