# Apex Financial — Security Dashboard PoC

## Overview
Proof of concept for real-time security monitoring dashboard
tailored for Apex Financial's compliance requirements.

## Stack
- Backend: Python (FastAPI)
- Frontend: React + TypeScript
- Database: PostgreSQL
- Monitoring: Prometheus + Grafana
